HTML and CSS Tasks For My IICT Course

Two small web page tasks made with basic HTML and CSS only (no JavaScript).

Task 03: Hotel Reservation Form

A form for the Continental Hotel, built with a table and styled with internal CSS (a <style> block inside tasks.html).

It includes:

Text boxes for name, email, mobile number and arrival time
A time picker for departure
Radio buttons for room type
Checkboxes for preferences and mode of payment
A drop-down to select a card
A Send Data button

Task 04: Victoria's Journal

A journal page organized with ids, classes, spans and divs, and styled with an external style sheet (task 4 style.css).

It uses:

Borders, margins and padding to make the boxes
Float to place the friends list and entries side by side
font-family and font-weight for the text
